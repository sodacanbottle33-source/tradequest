## 3. Money, units and rounding

1. Every price, cash balance, cost basis, proceeds and P&L value is an **integer number of cents**.
2. Share quantities are **integers â‰¥ 0**.
3. Because price Ã— quantity is integer Ã— integer, **buying and selling never needs rounding**. Rounding happens only in the three places below.
4. **Rounding rule (`roundHalfUp`)**: round to the nearest integer; exact halves round **up** (toward +âˆž). It is only ever applied to **non-negative** values.
   - For a ratio of integers `a / b` (with `a â‰¥ 0`, `b > 0`), compute with integer math: `floor((2Â·a + b) / (2Â·b))`. Do not divide in floating point first.
   - **Negative display values** (a negative return %, for example) are formatted by rounding the **magnitude** with `roundHalfUp` and then putting the minus sign back. So âˆ’0.005% shows as "âˆ’0.01%", the mirror image of +0.005% â†’ "0.01%". A value that rounds to zero shows without a sign ("0.00%").
5. **Where rounding is used:**
   - (a) **Price generation** (Â§5): each generated price is rounded to whole cents.
   - (b) **Cost basis removed on a partial sell** (Â§7.3).
   - (c) **Display only**: average entry price and percentage values. Displayed values are never fed back into calculations.
6. Dollar display: `cents / 100` shown with exactly 2 decimals (e.g. 253336 â†’ "$2,533.36"). Percentages shown with 2 decimals.
7. All integers must stay within JavaScript's safe-integer range. With the parameters above, values stay far below that limit; the code should still assert `Number.isSafeInteger` on stored values in development.

## 4. Round timeline and order of events

### 4.1 Indexing

There is **one global candle index `i` from 1 to 70**. All code uses this index.

| Indices | Kind | Tradable? |
|---------|------|-----------|
| 1â€“10 | History candles | **Never.** No order can fill at any price of these candles. |
| 11â€“70 | Playable candles | Orders fill at their **open**. End-of-round liquidation uses the **close of 70**. |

For display, a playable candle shows its **round number** `r = i âˆ’ 10` ("Candle 1 of 60" â€¦ "Candle 60 of 60"). History candles are labelled "History" and are visually distinct on the chart (e.g. dimmed or behind a "Round starts" divider).

### 4.2 Terms

- **Current index `k`**: the newest candle the player can see (10 to 70).
- **Visible candles**: candles 1..k, all four values (open, high, low, close).
- **Mark price**: close of candle k. Used for unrealized P&L and equity.
- **Pending order**: at most one order waiting to be filled on the next advance.

### 4.3 Round start

1. A seed is chosen (Â§8). All 70 candles are generated from it (Â§5).
2. Account is set to: cash = `START_CASH`, shares = 0, cost basis = 0, realized P&L = 0, no trades, no pending order, no notices.
3. **Candles 1â€“10 (all history) are shown immediately and in full.** k = 10. Mark price = closeâ‚â‚€. The round counter shows "Round starts next candle".
4. The player may now submit an order. It fills at the **open of candle 11** (the first playable candle) at the earliest.

So: the first decision is made with 10 candles of context, and the first possible fill is the open of the first playable candle â€” a price the player has not seen.

### 4.4 Each turn (while 10 â‰¤ k â‰¤ 69)

The player may, in any order and as many times as they like:

- view candles 1..k and their account;
- submit an order (Â§6), which becomes the pending order;
- cancel the pending order;
- submit a new order, which **replaces** the pending order (Â§6.4).

Then the player clicks **Next**. The advance runs these steps **in this exact order**:

1. Check k < 70. (If not, Next is not allowed â€” see Â§4.5.)
2. Read candle k+1 from the generated sequence. It is not yet visible.
3. If there is a pending order, process it at **fill price = openâ‚k+1â‚Ž**:
   - re-validate it (Â§6.3);
   - if valid, fill it and update the account (Â§7);
   - if invalid, reject it, leave the account unchanged and show the player why.
4. Clear the pending order (it was filled or rejected; it never carries over).
5. Set k = k + 1. Candle k is now visible in full.
6. Recompute mark price, unrealized P&L and equity at closeâ‚–.

Consequences:
- Because k starts at 10, the first advance reveals candle 11, so **every fill is at an index from 11 to 70**. History candles can never be traded at.
- There are exactly **60 advances** in a round and at most **one player fill per advance** (so at most 60 player trades).
- A fill price is always a price the player had **not** seen when they submitted the order.
- The player's actions can never change any candle (Â§5.5).

### 4.5 The last candle (k = 70)

1. When k = 70, **order entry is disabled**: no submit, no Next. There is no candle 71 to fill at.
2. There cannot be a pending order at this point (an order submitted at k = 69 was filled or rejected while advancing to 70).
3. The only available action is **Finish round**.

### 4.6 Finish round (end-of-round liquidation)

1. If shares > 0, the engine sells **all** shares at **closeâ‚‡â‚€** using the normal sell accounting (Â§7.3) and records it as a trade of type `liquidation`.
2. If shares = 0, no liquidation trade is recorded.
3. The round state becomes `FINISHED`. No further actions change the account; Finish is idempotent (doing it twice changes nothing).
4. Equity immediately before and after liquidation is identical (shares Ã— closeâ‚‡â‚€ becomes cash).
5. The results screen shows: seed, final equity, total return in $ and %, total realized P&L, number of player trades, and the full trade history.

> Liquidating at closeâ‚‡â‚€ is the one place a fill uses a price the player has already seen. This is acceptable because it is automatic, not a player decision, and only used to score the round.

### 4.7 Round states

`PLAYING` (k from 10 to 70) â†’ `FINISHED` (after Finish round). Reset (Â§9) can be used from either state.

An action that is not available in the current state â€” Next at k = 70, Finish before k = 70, Cancel with no pending order, or any order action after `FINISHED` â€” **returns the state unchanged** (the UI disables these controls, so no notice is needed). Order submissions that fail validation while `PLAYING` (Â§6.2) leave the account and pending order unchanged but add a notice explaining why.

## 5. Price engine

### 5.1 Seeded random number generator (RNG)

- Use **mulberry32**, a small, well-known 32-bit PRNG. Input: an unsigned 32-bit integer seed. Output: a stream of numbers `u` with 0 â‰¤ u < 1.
- **Reference implementation** (this exact code is the definition; the bitwise operators `| ^ >>>` and `Math.imul` are required by it and are allowed here â€” they are exact 32-bit integer operations and behave identically in every JavaScript engine):

  ```js
  // state starts as the seed (unsigned 32-bit integer)
  function next() {
    state = (state + 0x6d2b79f5) | 0;
    let t = Math.imul(state ^ (state >>> 15), 1 | state);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  }
  ```

- These integer operations are allowed **only inside the RNG**. The candle generator must take every random number from this RNG, in the fixed draw order of Â§5.3.
- **Why the same seed always gives the same candles:** a PRNG is not truly random. It is a fixed formula that turns an internal state into the next number and then updates the state. The seed is the starting state. Same seed â†’ same starting state â†’ the formula produces the **exact same stream of numbers, in the same order, every time**. If the candle generator (a) uses only that stream, (b) always consumes numbers in the same fixed order, and (c) does the same arithmetic, it must produce the same 70 candles.
- That determinism breaks if any of these happen, so they are **forbidden** in the engine:
  - calling `Math.random()`, `Date.now()` or anything else outside the seeded stream;
  - skipping or adding draws depending on conditions (e.g. "only draw a gap if i > 1", or different draws for history vs playable candles);
  - letting player actions consume random numbers;
  - using `Math.exp`, `Math.log`, `Math.sin`, `Math.cos`, `Math.pow`. These may differ in the last bits between browsers, which would matter for multiplayer later. Only `+ âˆ’ Ã— Ã·`, `Math.floor`, `Math.abs`, `Math.min`, `Math.max` are used.

### 5.2 Normal-ish random numbers without `log`/`cos`

`z = (uâ‚ + uâ‚‚ + â€¦ + uâ‚â‚‚) âˆ’ 6`

The sum of 12 uniform numbers has mean 6 and standard deviation 1, so `z` is approximately standard-normal and naturally bounded to [âˆ’6, +6]. Each `z` consumes exactly **12** draws.

### 5.3 Exact generation sequence (fixed)

History and playable candles are generated by **the same loop and the same formulas**. The only difference between them is how the game treats them (Â§4.1).

1. Draw **1** `u` â†’ start price: `START_PRICE_MIN + floor(u Ã— (START_PRICE_MAX âˆ’ START_PRICE_MIN + 1))`.
2. For each candle **i = 1, 2, â€¦, 70**, in order, draw exactly:
   1. `zGap` (12 draws)
   2. `zBody` (12 draws)
   3. `uUp` (1 draw)
   4. `uDown` (1 draw)

Draw positions (1-based):

| What | Draws |
|------|-------|
| Start price | 1 |
| Candle i | `2 + 26Â·(iâˆ’1)` to `1 + 26Â·i` |
| Candle 1 (history) | 2â€“27 |
| Candle 10 (last history) | 236â€“261 |
| Candle 11 (first playable) | 262â€“287 |
| Candle 70 (last) | 1796â€“1821 |
| **Total per round** | **1821** |

Candle 1 still consumes its `zGap` even though it is not used.

### 5.4 Candle formulas

Let `clamp(x, lo, hi) = min(max(x, lo), hi)`. For candle i:

- **Open**
  - i = 1: `openâ‚ = startPrice`
  - i â‰¥ 2: `gap = clamp(GAP_SIGMA Ã— zGap, âˆ’MAX_GAP, +MAX_GAP)`; `openáµ¢ = max(MIN_PRICE, roundHalfUp(closeáµ¢â‚‹â‚ Ã— (1 + gap)))`
- **Close**
  - `ret = clamp(DRIFT + BODY_SIGMA Ã— zBody, âˆ’MAX_MOVE, +MAX_MOVE)`
  - `closeáµ¢ = max(MIN_PRICE, roundHalfUp(openáµ¢ Ã— (1 + ret)))`
- **High**: `higháµ¢ = roundHalfUp(max(openáµ¢, closeáµ¢) Ã— (1 + uUp Ã— WICK_MAX))`
- **Low**: `lowáµ¢ = max(MIN_PRICE, roundHalfUp(min(openáµ¢, closeáµ¢) Ã— (1 âˆ’ uDown Ã— WICK_MAX)))`

(Here `roundHalfUp` of a floating-point value is `floor(x + 0.5)`; inputs are positive.)

The gap into candle 11 is generated exactly like every other gap: the first playable open is closeâ‚â‚€ moved by a small random gap.

**Guaranteed properties of every candle** (checked by tests):
- all four values are integers â‰¥ `MIN_PRICE`;
- `low â‰¤ min(open, close)` and `high â‰¥ max(open, close)`;
- open-to-close move within Â±`MAX_MOVE` (before the `MIN_PRICE` floor and rounding);
- gap from previous close within Â±`MAX_GAP` (before floor and rounding).

### 5.5 Independence from the player

All 70 candles are generated at round start from the seed alone. Trades, cancels, timing and clicks never touch the RNG. Therefore **the same seed gives the same market no matter how the player trades.**

The UI and any state the UI reads must only expose candles 1..k. (In single-player, a determined user could inspect memory with dev tools; that is acceptable for Milestone 1 and is solved later with server-side rounds.)

### 5.6 Engine version

`ENGINE_VERSION = 1`. Any change to the formulas, draw order, candle counts or tunable parameters changes the candles for a given seed and must bump the version. A round is identified by `(ENGINE_VERSION, seed)`.

**Golden values must be independent.** The expected RNG outputs and the candle snapshot used by the tests are produced by a separate reference implementation (`tools/reference_engine.py`, written in Python directly from this spec), never by running the TypeScript code being tested. Hand-computed candles (ENG-13, HIST-01) are worked out on paper from the formulas. If the TypeScript engine and the reference disagree, one of them is wrong and must be investigated â€” the fixture must not simply be regenerated to make a test pass. Regenerating the fixture is only allowed together with an `ENGINE_VERSION` bump.

### 5.7 What this model is (and isn't)

A plain random walk with small gaps â€” no trends, no news, no expectations. That is intentional for Milestone 1: it lets us test trading and accounting on a neutral market. News, expectations and surprises are Milestone 2 and will be added as additional, documented draws (with an engine-version bump).

## 6. Orders

### 6.1 Order fields

- `side`: `BUY` or `SELL`
- `quantity`: integer
- `submittedAt`: the index k when submitted

### 6.2 Validation at submission

An order is accepted as pending only if **all** of these hold:

1. Round state is `PLAYING` and k < 70.
2. Quantity is an integer with 1 â‰¤ quantity â‰¤ `MAX_ORDER_QTY`. The input text must consist only of the digits 0â€“9 and must not start with 0 (pattern `^[1-9][0-9]*$`): no decimals, signs, spaces, exponents, leading zeros or empty input.
3. `SELL`: quantity â‰¤ shares held.
4. `BUY`: estimated cost `quantity Ã— closeâ‚–` â‰¤ cash. This is only an **estimate**; the UI labels it "Est. cost at last close".

If any check fails, the order is not accepted and the player sees which rule failed. A failed submission does **not** remove an existing pending order.

### 6.3 Validation at fill (authoritative)

Re-checked during advance step 3 with fill price `P = openâ‚k+1â‚Ž`:

- `BUY`: `quantity Ã— P â‰¤ cash`. If not, the **whole order is rejected** â€” no partial fill. Message: "Order rejected: the price opened at $X. This order would cost $Y, but you have $Z."
- `SELL`: `quantity â‰¤ shares held` (always true in Milestone 1, but checked defensively).

Rejected orders do not appear in trade history; they appear as a notice.

### 6.4 Replacing a pending order

If a valid order is submitted while another is pending, the new order replaces the old one and the player sees a notice, e.g. "Previous order (BUY 5) replaced by BUY 8." Cancelling shows "Order cancelled."

### 6.5 Helper: "Max" button (optional UI)

Fills the quantity box with `floor(cash / closeâ‚–)` for buys, or shares held for sells. Because buys fill at the next open, a max buy can still be rejected if the price gaps up. This is expected and a good teaching moment.

## 7. Account accounting

### 7.1 Account state

| Field | Type | Start |
|-------|------|-------|
| `cash` | cents | 100000 |
| `shares` | integer | 0 |
| `costBasis` | cents â€” total cost of the shares currently held | 0 |
| `realizedPnl` | cents â€” running total | 0 |
| `trades` | list | empty |

Average entry price is **not stored**; it is derived (Â§7.4).

### 7.2 Buy fill (quantity q at price P)

- `cost = q Ã— P`
- `cash -= cost`
- `shares += q`
- `costBasis += cost`

### 7.3 Sell fill (quantity q at price P, with q â‰¤ shares)

- `proceeds = q Ã— P`
- `removedBasis = roundHalfUp(costBasis Ã— q / shares)` (integer formula from Â§3.4, using values **before** this sell)
- `tradePnl = proceeds âˆ’ removedBasis`
- `cash += proceeds`
- `shares -= q`
- `costBasis -= removedBasis`
- `realizedPnl += tradePnl`

When q = shares (full close), `removedBasis = costBasis` exactly, so costBasis returns to 0 with no leftover cents.

### 7.4 Derived values

- **Average entry price** (display only): `roundHalfUp(costBasis / shares)` cents; "â€”" when shares = 0.
- **Position value**: `shares Ã— markPrice`
- **Unrealized P&L**: `shares Ã— markPrice âˆ’ costBasis`
- **Equity**: `cash + shares Ã— markPrice`
- **Total return**: `equity âˆ’ START_CASH`; percentage `(equity âˆ’ START_CASH) / START_CASH Ã— 100` (display only).

### 7.5 Invariants (must always hold)

1. `cash â‰¥ 0`, `shares â‰¥ 0`, `costBasis â‰¥ 0`, all integers.
2. `shares = 0` â‡” `costBasis = 0`.
3. **`equity = START_CASH + realizedPnl + unrealizedPnl`**, exactly, to the cent.
4. `cash = START_CASH âˆ’ Î£(buy costs) + Î£(sell proceeds)`.
5. Shares held = Î£(bought) âˆ’ Î£(sold).
6. Every player trade has `candleIndex` between 11 and 70 and `price = openâ‚candleIndexâ‚Ž`; a liquidation trade has `candleIndex = 70` and `price = closeâ‚‡â‚€`.

### 7.6 Trade record

Each fill appends one record:

`id` (1, 2, 3â€¦), `type` (`player` | `liquidation`), `side`, `candleIndex` (global index 11â€“70), `quantity`, `price`, `amount` (cost or proceeds), `tradePnl` (sells only), `cashAfter`, `sharesAfter`. The UI shows the round number (`candleIndex âˆ’ 10`).

## 8. Seeds

- A new round's seed is a random unsigned 32-bit integer from `crypto.getRandomValues` (the only real randomness; it is outside the engine).
- The seed is shown on the results screen (and may be shown in a small debug area) so a round can be replayed or a bug reported.

## 9. Reset behaviour

- **New round**: new random seed; everything in Â§4.3 is reset; candles 1â€“10 shown, k = 10.
- **Replay this round**: same seed; everything reset; all 70 candles are identical to the previous attempt.
- Both are available while `PLAYING` (with a confirmation prompt) and after `FINISHED` (no prompt).
- Reset discards the pending order, trades and notices from the old round.
- **No persistence in Milestone 1**: refreshing the page loses the round.

### General rules for the test suite

- **Independent expected values.** Golden values (RNG-05, ENG-04, HIST-01's snapshot check) come from `tools/reference_engine.py`, a separate Python implementation written from the spec, and are stored in `tests/fixtures/`. Hand-computed cases (ENG-13, ENG-14, HIST-01) are worked out from the formulas and written into the test as literal numbers. **No expected value is ever produced by the TypeScript code under test.**
- **Reproducible property tests.** Every P test runs from a fixed base seed. When a case fails, the error message must include the market seed and the full action sequence (as JSON) so the failure can be replayed exactly with `replayActions(seed, actions)`.
- If a test exposes a bug, fix the code â€” do not weaken the test.

export interface RandomValuesSource {
  getRandomValues(array: Uint32Array<ArrayBuffer>): unknown;
}

/** Random unsigned 32-bit seed from crypto.getRandomValues. `source` is replaceable for tests. */
export function randomSeed(source: RandomValuesSource = globalThis.crypto): number {
  const buffer = new Uint32Array(1);
  source.getRandomValues(buffer);
  return buffer[0] ?? 0;

// React glue: holds the RoundState privately and exposes only the safe view (rules.md Â§5.5).
import { useCallback, useMemo, useReducer } from 'react';
import {
  advance,
  cancelOrder,
  createRound,
  finishRound,
  getResults,
  getView,
  replayRound,
  submitOrder,
  type RoundResults,
  type RoundState,
  type RoundView,
  type Side,
} from '../engine';
import { randomSeed } from './seed';

type RoundAction =
  | { type: 'submit'; side: Side; quantityText: string }
  | { type: 'cancel' }
  | { type: 'next' }
  | { type: 'finish' }
  | { type: 'newRound'; seed: number }
  | { type: 'replay' };

function reducer(state: RoundState, action: RoundAction): RoundState {
  switch (action.type) {
    case 'submit':
      return submitOrder(state, action.side, action.quantityText);
    case 'cancel':
      return cancelOrder(state);
    case 'next':
      return advance(state);
    case 'finish':
      return finishRound(state);
    case 'newRound':
      return createRound(action.seed);
    case 'replay':
      return replayRound(state);
  }
}

export interface RoundControls {
  view: RoundView;
  results: RoundResults | null;
  submit: (side: Side, quantityText: string) => void;
  cancel: () => void;
  next: () => void;
  finish: () => void;
  newRound: () => void;
  replay: () => void;
}

  const [state, dispatch] = useReducer(reducer, undefined, () => createRound(randomSeed()));
  const view = useMemo(() => getView(state), [state]);
  const results = useMemo(() => getResults(state), [state]);

  return {
    view,
    results,
    submit: useCallback((side: Side, quantityText: string) => dispatch({ type: 'submit', side, quantityText }), []),
    cancel: useCallback(() => dispatch({ type: 'cancel' }), []),
    next: useCallback(() => dispatch({ type: 'next' }), []),

// Account accounting â€” see docs/rules.md Â§7.
// Callers validate orders first; these functions throw only on programming errors.

import { START_CASH } from './constants';
import { assertMoney, roundHalfUpRatio } from './money';

export interface Account {
  /** Cents. */
  readonly cash: number;
  /** Whole shares held. */
  readonly shares: number;
  /** Cents â€” total cost of the shares currently held. */
  readonly costBasis: number;
  /** Cents â€” running total of realized P&L. */
  readonly realizedPnl: number;
}

export function initialAccount(): Account {
  return { cash: START_CASH, shares: 0, costBasis: 0, realizedPnl: 0 };
}

function checkFill(quantity: number, price: number): void {
  if (!Number.isSafeInteger(quantity) || quantity < 1) throw new Error(`Invalid quantity ${quantity}`);
  if (!Number.isSafeInteger(price) || price < 1) throw new Error(`Invalid price ${price}`);
}

function checkAccount(a: Account): Account {
  assertMoney(a.cash, 'cash');
  assertMoney(a.shares, 'shares');
  assertMoney(a.costBasis, 'costBasis');
  assertMoney(a.realizedPnl, 'realizedPnl');
  return a;
}

/** Buy fill (Â§7.2). */
export function applyBuy(account: Account, quantity: number, price: number): { account: Account; cost: number } {
  checkFill(quantity, price);
  const cost = quantity * price;
  if (cost > account.cash) throw new Error(`Buy costs ${cost} but cash is ${account.cash}`);
  return {
    cost,
    account: checkAccount({
      cash: account.cash - cost,
      shares: account.shares + quantity,
      costBasis: account.costBasis + cost,
      realizedPnl: account.realizedPnl,
    }),
  };
}

/** Sell fill (Â§7.3). removedBasis uses the values BEFORE the sell. */
export function applySell(
  account: Account,
  quantity: number,
  price: number,
): { account: Account; proceeds: number; removedBasis: number; tradePnl: number } {
  checkFill(quantity, price);
  if (quantity > account.shares) throw new Error(`Cannot sell ${quantity}, holding ${account.shares}`);
  const proceeds = quantity * price;
  const removedBasis = roundHalfUpRatio(account.costBasis * quantity, account.shares);
  const tradePnl = proceeds - removedBasis;
  return {
    proceeds,
    removedBasis,
    tradePnl,
    account: checkAccount({
      cash: account.cash + proceeds,
      shares: account.shares - quantity,
      costBasis: account.costBasis - removedBasis,
      realizedPnl: account.realizedPnl + tradePnl,
    }),
  };
}

// ----- Derived values (Â§7.4) -----

export function positionValue(account: Account, markPrice: number): number {
  return account.shares * markPrice;
}

export function unrealizedPnl(account: Account, markPrice: number): number {
  return account.shares * markPrice - account.costBasis;
}

export function equity(account: Account, markPrice: number): number {
  return account.cash + account.shares * markPrice;
}

/** Display only. null when no shares are held. */
export function averageEntry(account: Account): number | null {
  return account.shares > 0 ? roundHalfUpRatio(account.costBasis, account.shares) : null;
}

/** Creates a stream: draws the start price immediately, then one candle per next() call. */
export function createCandleStream(rng: RandomSource): CandleStream {
  const startPrice = startPriceFrom(rng.next());
  let index = 0;
  let prevClose = 0;

  return {
    startPrice,
    next(): Candle {
      index += 1;
      // Fixed draw order: always all four, even when a value is unused (Â§5.3).
      const zGap = normalZ(rng);
      const zBody = normalZ(rng);
      const uUp = rng.next();
      const uDown = rng.next();

      let open: number;
      if (index === 1) {
        open = startPrice;
      } else {
        const gap = clamp(GAP_SIGMA * zGap, -MAX_GAP, MAX_GAP);
        open = Math.max(MIN_PRICE, roundHalfUpFloat(prevClose * (1 + gap)));
      }

      const ret = clamp(DRIFT + BODY_SIGMA * zBody, -MAX_MOVE, MAX_MOVE);
      const close = Math.max(MIN_PRICE, roundHalfUpFloat(open * (1 + ret)));
      const high = roundHalfUpFloat(Math.max(open, close) * (1 + uUp * WICK_MAX));
      const low = Math.max(MIN_PRICE, roundHalfUpFloat(Math.min(open, close) * (1 - uDown * WICK_MAX)));

      prevClose = close;
      return { index, open, high, low, close };
    },
  };
}

/** Generates `count` candles from an RNG (default: a full round of 70). */
export function generateCandlesFromRng(rng: RandomSource, count: number = TOTAL_CANDLES): Candle[] {
  const stream = createCandleStream(rng);
  const candles: Candle[] = [];
  for (let i = 0; i < count; i += 1) candles.push(stream.next());
  return candles;
}

/** All 70 candles for a seed. Same seed â†’ same candles, always. */
export function generateCandles(seed: number): Candle[] {
  return generateCandlesFromRng(new Mulberry32(seed));
}

/** History candles are indices 1â€“10 (Â§4.1). */

  return index >= 1 && index <= HISTORY_LENGTH;
}

/** Round number for display: index âˆ’ 10 (11 â†’ 1, 70 â†’ 60). 0 or less means history. */
export function roundNumber(index: number): number {
  return index - HISTORY_LENGTH;

const MINUS = 'âˆ’'; // "âˆ’", a real minus sign

function groupThousands(n: number): string {
  return String(n).replace(/\B(?=(\d{3})+(?!\d))/g, ',');
}

/** 253336 â†’ "$2,533.36"; âˆ’1467 â†’ "âˆ’$14.67". */
export function formatCents(cents: number): string {
  const abs = Math.abs(cents);
  const dollars = Math.floor(abs / 100);
  const rest = abs % 100;
  const text = `$${groupThousands(dollars)}.${String(rest).padStart(2, '0')}`;
  return cents < 0 ? `${MINUS}${text}` : text;
}

/** Like formatCents but shows "+" for positive values (used for P&L). */
export function formatSignedCents(cents: number): string {
  return cents > 0 ? `+${formatCents(cents)}` : formatCents(cents);
}

/**
 * Percentage `part / whole Ã— 100`, shown with 2 decimals.
 * The magnitude is rounded half-up, then the sign is applied (Â§3.4);
 * a value that rounds to zero has no sign.
 */
export function formatPercent(part: number, whole: number): string {
  const hundredths = roundHalfUpRatio(Math.abs(part) * 10_000, whole);
  const text = `${Math.floor(hundredths / 100)}.${String(hundredths % 100).padStart(2, '0')}%`;
  return part < 0 && hundredths > 0 ? `${MINUS}${text}` : text;
}

/** Like formatPercent but shows "+" for positive values. */
export function formatSignedPercent(part: number, whole: number): string {
  const text = formatPercent(part, whole);
  return part > 0 && text !== '0.00%' ? `+${text}` : text;
}

// Integer-cent helpers â€” see docs/rules.md Â§3.

function assertSafeInteger(value: number, name: string): void {
  if (!Number.isSafeInteger(value)) {
    throw new Error(`${name} must be a safe integer, got ${value}`);
  }
}

/**
 * roundHalfUp(a / b) for integers a â‰¥ 0, b > 0, computed exactly.
 * Formula: floor((2a + b) / (2b)). The floating-point division only gives a
 * first guess; the two correction loops make the result exact.
 */
export function roundHalfUpRatio(a: number, b: number): number {
  assertSafeInteger(a, 'a');
  assertSafeInteger(b, 'b');
  if (a < 0) throw new Error(`roundHalfUpRatio needs a â‰¥ 0, got ${a}`);
  if (b <= 0) throw new Error(`roundHalfUpRatio needs b > 0, got ${b}`);
  const num = 2 * a + b;
  const den = 2 * b;
  assertSafeInteger(num, '2a + b');
  return floorDiv(num, den);
}

/** floor(a / b) for integers a â‰¥ 0, b > 0, computed exactly. */
export function floorDiv(a: number, b: number): number {
  assertSafeInteger(a, 'a');
  assertSafeInteger(b, 'b');
  if (a < 0 || b <= 0) throw new Error(`floorDiv needs a â‰¥ 0 and b > 0, got ${a}, ${b}`);
  let q = Math.floor(a / b);
  while (q * b > a) q -= 1;
  while ((q + 1) * b <= a) q += 1;
  return q;
}

/** roundHalfUp of a positive floating-point price: floor(x + 0.5). Used only by the price engine (Â§5.4). */
export function roundHalfUpFloat(x: number): number {
  return Math.floor(x + 0.5);
}

/** Development check that a stored money/share value is a safe integer (Â§3.7). */
export function assertMoney(value: number, name: string): void {
  assertSafeInteger(value, name);
}

// Seeded random number generator â€” see docs/rules.md Â§5.1â€“5.2.
// This is the ONLY file in the engine allowed to use bitwise operators and Math.imul.

export interface RandomSource {
  /** Next number u with 0 â‰¤ u < 1. */
  next(): number;
}

export class Mulberry32 implements RandomSource {
  private state: number;
  /** How many numbers have been drawn so far (used by tests to check draw order). */
  draws = 0;

  constructor(seed: number) {
    if (!Number.isInteger(seed) || seed < 0 || seed > 0xffffffff) {
      throw new Error(`Seed must be an unsigned 32-bit integer, got ${seed}`);
    }
    this.state = seed;
  }

  next(): number {
    this.draws += 1;
    this.state = (this.state + 0x6d2b79f5) | 0;
    let t = Math.imul(this.state ^ (this.state >>> 15), 1 | this.state);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  }
}

/** Approximately standard-normal number: sum of 12 uniforms minus 6. Uses exactly 12 draws (Â§5.2). */
export function normalZ(rng: RandomSource): number {
  let sum = 0;
  for (let i = 0; i < 12; i += 1) sum += rng.next();
  return sum - 6;
}

/** Submit an order (Â§6.2). Replaces any pending order (Â§6.4). */
export function submitOrder(state: RoundState, side: Side, quantityText: string): RoundState {
  if (state.status !== 'PLAYING') return state;
  if (state.k >= LAST_INDEX) {
    return addNotice(state, 'error', 'No next candle: this is the final candle. Finish the round to see your results.');
  }

  const parsed = parseQuantity(quantityText);
  if (!parsed.ok) return addNotice(state, 'error', parsed.reason);
  const quantity = parsed.value;
  const { account } = state;

  if (side === 'SELL') {
    if (account.shares === 0) return addNotice(state, 'error', "You don't hold any shares to sell.");
    if (quantity > account.shares) {
      return addNotice(state, 'error', `You only hold ${account.shares} share${account.shares === 1 ? '' : 's'}.`);
    }
  } else {
    const estimate = quantity * markPrice(state);
    if (estimate > account.cash) {
      return addNotice(
        state,
        'error',
        `Not enough cash: estimated cost ${formatCents(estimate)} at the last close, but you have ${formatCents(account.cash)}.`,
      );
    }
  }

  const previous = state.pending;
  const next: RoundState = { ...state, pending: { side, quantity, submittedAt: state.k } };
  const message = previous
    ? `Previous order (${describeOrder(previous.side, previous.quantity)}) replaced by ${describeOrder(side, quantity)}.`
    : `Order placed: ${describeOrder(side, quantity)}. It fills at the next candle's open.`;
  return addNotice(next, 'info', message);
}

export function cancelOrder(state: RoundState): RoundState {
  if (state.status !== 'PLAYING' || state.pending === null) return state;
  return addNotice({ ...state, pending: null }, 'info', 'Order cancelled.');
}

/** Reveal the next candle, filling any pending order at its open (Â§4.4, steps 1â€“6). */
export function advance(state: RoundState): RoundState {
  // 1. Check k < 70.
  if (state.status !== 'PLAYING' || state.k >= LAST_INDEX) return state;

  // 2. Read candle k+1 (not visible yet).
  const nextIndex = state.k + 1;
  const nextCandle = candleAt(state, nextIndex);
  let result: RoundState = state;

  // 3. Process the pending order at open(k+1).
  const order = state.pending;
  if (order) {
    const price = nextCandle.open;
    const { account } = state;
    if (order.side === 'BUY') {
      const cost = order.quantity * price;
      if (cost > account.cash) {
        result = addNotice(
          result,
          'error',
          `Order rejected: the price opened at ${formatCents(price)}. This order would cost ${formatCents(cost)}, but you have ${formatCents(account.cash)}.`,
        );
      } else {
        const fill = applyBuy(account, order.quantity, price);
        result = recordTrade(result, fill.account, {
          type: 'player',
          side: 'BUY',
          candleIndex: nextIndex,
          quantity: order.quantity,
          price,
          amount: fill.cost,
          tradePnl: null,
        });
        result = addNotice(
          result,
          'success',
          `Bought ${order.quantity} at ${formatCents(price)} (${candleLabel(nextIndex)} open). Cost ${formatCents(fill.cost)}.`,
        );
      }
    } else if (order.quantity > account.shares) {
      result = addNotice(result, 'error', `Order rejected: you hold only ${account.shares} shares.`);
    } else {
      const fill = applySell(account, order.quantity, price);
      result = recordTrade(result, fill.account, {
        type: 'player',
        side: 'SELL',
        candleIndex: nextIndex,
        quantity: order.quantity,
        price,
        amount: fill.proceeds,
        tradePnl: fill.tradePnl,
      });
      result = addNotice(
        result,
        'success',
        `Sold ${order.quantity} at ${formatCents(price)} (${candleLabel(nextIndex)} open). Realized P&L ${formatSignedCents(fill.tradePnl)}.`,
      );
    }
  }

  // 4. Clear the pending order. 5. Reveal candle k+1. (6. Marks are derived in view.ts.)
  return { ...result, pending: null, k: nextIndex };
}

/** Finish the round: liquidate at close(70) and mark FINISHED (Â§4.6). Idempotent. */
export function finishRound(state: RoundState): RoundState {
  if (state.status !== 'PLAYING' || state.k !== LAST_INDEX) return state;
  let result: RoundState = state;
  const { account } = state;
  if (account.shares > 0) {
    const price = candleAt(state, LAST_INDEX).close;
    const fill = applySell(account, account.shares, price);
    result = recordTrade(result, fill.account, {
      type: 'liquidation',
      side: 'SELL',
      candleIndex: LAST_INDEX,
      quantity: account.shares,
      price,
      amount: fill.proceeds,
      tradePnl: fill.tradePnl,
    });
    result = addNotice(
      result,
      'info',
      `Round finished. Your remaining ${account.shares} shares were sold at the final close, ${formatCents(price)}.`,
    );
  } else {
    result = addNotice(result, 'info', 'Round finished.');
  }
  return { ...result, status: 'FINISHED', pending: null };
}

function recordTrade(
  state: RoundState,
  account: Account,
  t: Omit<Trade, 'id' | 'cashAfter' | 'sharesAfter'>,

  const trade: Trade = {
    ...t,
    id: state.trades.length + 1,
    cashAfter: account.cash,
    sharesAfter: account.shares,
  };
  return { ...state, account, trades: [...state.trades, trade] };
}

  const { candles, markPrice } = view;
  const current = candles[candles.length - 1];

  let lo = Math.min(...candles.map((c) => c.low));
  let hi = Math.max(...candles.map((c) => c.high));
  const pad = Math.max((hi - lo) * 0.08, 10);
  lo -= pad;
  hi += pad;
  const y = (price: number) => PAD.top + ((hi - price) / (hi - lo)) * PLOT_H;
  const xCenter = (index: number) => PAD.left + (index - 0.5) * SLOT;
  const bodyW = Math.max(2, SLOT * 0.62);

  const ticks = [0, 1, 2, 3, 4].map((i) => lo + ((hi - lo) * i) / 4);
  const dividerX = PAD.left + HISTORY_LENGTH * SLOT;

  return (
    <div className="chart">
      <div className="chart-head">
        <div className="chart-title">
          <span className="round-counter">{roundCounterLabel(view)}</span>
          {current && (
            <span className="ohlc">
              {current.kind === 'history' ? 'History Â· ' : ''}O {formatCents(current.open)} H {formatCents(current.high)} L{' '}
              {formatCents(current.low)} C {formatCents(current.close)}
            </span>
          )}
        </div>
        <div className="legend">
          <span className="legend-history">History (not tradable)</span>
          <span className="legend-round">Round</span>
        </div>
      </div>
      <svg
        viewBox={`0 0 ${W} ${H}`}
        className="chart-svg"
        role="img"
        aria-label={`Candlestick chart, ${candles.length} candles shown, last close ${formatCents(markPrice)}`}
      >
        <rect x={PAD.left} y={PAD.top} width={HISTORY_LENGTH * SLOT} height={PLOT_H} className="history-zone" />
        {ticks.map((t) => (
          <g key={t}>
            <line x1={PAD.left} x2={PAD.left + PLOT_W} y1={y(t)} y2={y(t)} className="grid" />
            <text x={W - PAD.right + 6} y={y(t) + 4} className="axis-label">
              {(t / 100).toFixed(2)}
            </text>
          </g>
        ))}
        <line x1={dividerX} x2={dividerX} y1={PAD.top} y2={PAD.top + PLOT_H} className="divider" />
        <text x={dividerX + 4} y={H - 8} className="divider-label">
          Round starts â–¸
        </text>
        <text x={PAD.left + 4} y={H - 8} className="divider-label">
          History
        </text>

        {candles.map((c) => {
          const up = c.close >= c.open;
          const top = y(Math.max(c.open, c.close));
          const bottom = y(Math.min(c.open, c.close));
          const cls = `candle ${up ? 'up' : 'down'} ${c.kind === 'history' ? 'is-history' : ''}`;
          return (
            <g key={c.index} className={cls}>
              <line x1={xCenter(c.index)} x2={xCenter(c.index)} y1={y(c.high)} y2={y(c.low)} className="wick" />
              <rect
                x={xCenter(c.index) - bodyW / 2}
                y={top}
                width={bodyW}
                height={Math.max(1, bottom - top)}
                className="body"
              />
            </g>
          );
        })}

        <line x1={PAD.left} x2={PAD.left + PLOT_W} y1={y(markPrice)} y2={y(markPrice)} className="mark-line" />
        <rect x={W - PAD.right + 2} y={y(markPrice) - 10} width={PAD.right - 4} height={20} rx={3} className="mark-tag" />
        <text x={W - PAD.right + 6} y={y(markPrice) + 4} className="mark-text">

// Small display helpers shared by components (kept separate so they can be unit-tested).
import type { RoundView } from '../engine';

/** Round counter text (FLOW-17): "Round starts next candle" at k = 10, then "Candle r of 60". */
export function roundCounterLabel(view: Pick<RoundView, 'roundNumber' | 'roundLength'>): string {
  return view.roundNumber === 0 ? 'Round starts next candle' : `Candle ${view.roundNumber} of ${view.roundLength}`;
}

/** Label for a trade's candle in the history table. */
export function tradeCandleLabel(candleIndex: number, type: 'player' | 'liquidation'): string {
  const r = candleIndex - 10;
  return type === 'liquidation' ? `${r} (close)` : `${r} (open)`;
}

// FLOW-02: checks that the UI-facing view never contains future candles.
import type { RoundState, RoundView } from '../../src/engine';

function isCandleLike(v: unknown): v is { index: number } {
  return (
    typeof v === 'object' &&
    v !== null &&
    typeof (v as Record<string, unknown>).index === 'number' &&
    'open' in v &&
    'close' in v
  );
}

/** Throws if anything in `view` reveals a candle after k. */
export function assertNoFutureCandles(view: RoundView, state: RoundState): void {
  const k = state.k;
  const future = new Set<unknown>(state.candles.slice(k));
  if (view.candles.length !== k) throw new Error(`view has ${view.candles.length} candles, expected ${k}`);

  const seen = new Set<unknown>();
  const walk = (value: unknown, path: string): void => {
    if (typeof value !== 'object' || value === null || seen.has(value)) return;
    seen.add(value);
    if (future.has(value)) throw new Error(`future candle object exposed at ${path}`);
    if (value === state.candles) throw new Error(`full candle list exposed at ${path}`);
    if (isCandleLike(value) && value.index > k) throw new Error(`candle ${value.index} exposed at ${path} (k = ${k})`);
    if (Array.isArray(value) && value.length > k && value.some(isCandleLike)) {
      throw new Error(`list of ${value.length} candles exposed at ${path}`);
    }
    for (const [key, child] of Object.entries(value)) walk(child, `${path}.${key}`);
  };
  walk(view, 'view');
}

// Reproducible property testing (test-cases.md "General rules").
// Every case uses a fixed seed; a failure reports the market seed and the full
// action sequence, which replayActions() can run again exactly.

import {
  advance,
  cancelOrder,
  createRound,
  finishRound,
  getView,
  Mulberry32,
  replayRound,
  submitOrder,
  type RoundState,
  type Side,
} from '../../src/engine';

export type Action =
  | { type: 'submit'; side: Side; qty: string }
  | { type: 'cancel' }
  | { type: 'advance' }
  | { type: 'finish' }
  | { type: 'replay' };

export function applyAction(state: RoundState, action: Action): RoundState {
  switch (action.type) {
    case 'submit':
      return submitOrder(state, action.side, action.qty);
    case 'cancel':
      return cancelOrder(state);
    case 'advance':
      return advance(state);
    case 'finish':
      return finishRound(state);
    case 'replay':
      return replayRound(state);
  }
}

/** Re-runs a recorded action sequence from scratch. */
export function replayActions(seed: number, actions: readonly Action[]): RoundState {
  return actions.reduce(applyAction, createRound(seed));
}

const INVALID_QUANTITIES = ['0', '-3', '1.5', '', ' ', 'abc', '1e3', '+5', ' 5', '05', '1000001'];

/** Picks a random action â€” valid and invalid ones (test-cases.md Â§12). */
export function randomAction(rng: Mulberry32, state: RoundState): Action {
  const r = rng.next();
  if (state.k === 70 && r < 0.3) return { type: 'finish' };
  if (r < 0.42) return { type: 'advance' };
  if (r < 0.84) {
    const side: Side = rng.next() < 0.55 ? 'BUY' : 'SELL';
    const v = getView(state);
    const q = rng.next();
    let qty: string;
    if (q < 0.1) qty = INVALID_QUANTITIES[Math.floor(rng.next() * INVALID_QUANTITIES.length)] ?? '0';
    else if (q < 0.3) qty = String(side === 'BUY' ? Math.max(1, v.maxBuyQuantity) : Math.max(1, v.maxSellQuantity));
    else {
      const cap = side === 'BUY' ? v.maxBuyQuantity : v.maxSellQuantity;
      qty = String(1 + Math.floor(rng.next() * (cap + 3)));
    }
    return { type: 'submit', side, qty };
  }
  if (r < 0.93) return { type: 'cancel' };
  if (r < 0.995) return { type: 'finish' };
  return { type: 'replay' };
}

export class PropertyFailure extends Error {
  constructor(
    readonly seed: number,
    readonly actions: readonly Action[],
    cause: unknown,
  ) {
    super(
      `Property failed for market seed ${seed} after ${actions.length} actions.\n` +
        `Reproduce with: replayActions(${seed}, ${JSON.stringify(actions)})\n` +
        `Cause: ${cause instanceof Error ? cause.message : String(cause)}`,
    );
    this.name = 'PropertyFailure';
  }
}

export interface PropertyOptions {
  cases: number;
  baseSeed: number;
  steps: number;
}

/**
 * Runs `cases` random action sequences. After every action, `check(next, prev, action)` runs.
 * Any thrown error is re-thrown as a PropertyFailure with the seed and actions.
 */
export function forEachRandomRun(
  options: PropertyOptions,
  check: (next: RoundState, prev: RoundState, action: Action) => void,
): void {
  for (let i = 0; i < options.cases; i += 1) {
    const seed = (options.baseSeed + Math.imul(i, 0x9e3779b1)) >>> 0;
    const actionRng = new Mulberry32((seed ^ 0x5bd1e995) >>> 0);
    const actions: Action[] = [];
    let state = createRound(seed);
    try {
      for (let step = 0; step < options.steps; step += 1) {
        const action = randomAction(actionRng, state);
        actions.push(action);
        const next = applyAction(state, action);
        check(next, state, action);
        state = next;
      }
    } catch (err) {
      throw new PropertyFailure(seed, actions, err);
    }
  }
}

// Test helpers: build rounds with exact, hand-chosen prices.

import {
  createRoundFromCandles,
  TOTAL_CANDLES,
  advance,
  type Candle,
  type RandomSource,
  type RoundState,
} from '../../src/engine';

type CandleOverride = Partial<Omit<Candle, 'index'>>;

/**
 * 70 flat candles at `price`, with optional overrides by global index.
 * high/low default to max/min of open and close so every candle stays valid.
 */
export function makeCandles(price: number, overrides: Record<number, CandleOverride> = {}): Candle[] {
  const candles: Candle[] = [];
  for (let index = 1; index <= TOTAL_CANDLES; index += 1) {
    const o = overrides[index] ?? {};
    const open = o.open ?? price;
    const close = o.close ?? price;
    candles.push({
      index,
      open,
      close,
      high: o.high ?? Math.max(open, close),
      low: o.low ?? Math.min(open, close),
    });
  }
  return candles;
}

export function makeRound(price: number, overrides: Record<number, CandleOverride> = {}, seed = 42): RoundState {
  return createRoundFromCandles(seed, makeCandles(price, overrides));
}

/** Advance until the newest visible candle is `k`. */
export function advanceTo(state: RoundState, k: number): RoundState {
  let s = state;
  while (s.k < k) {
    const next = advance(s);
    if (next === s) throw new Error(`Could not advance past ${s.k}`);
    s = next;
  }
  return s;
}

/** RNG stub: returns scripted values by 1-based draw position, `fallback` otherwise. Counts draws. */
export class ScriptedRng implements RandomSource {
  draws = 0;
  constructor(
    private readonly script: Record<number, number> = {},
    private readonly fallback = 0.5,
  ) {}
  next(): number {
    this.draws += 1;
    return this.script[this.draws] ?? this.fallback;
  }
}

/** Fills positions [from, from+count) of a script with one value. */
export function fill(script: Record<number, number>, from: number, count: number, value: number): void {
  for (let p = from; p < from + count; p += 1) script[p] = value;
}

function checkInvariants(next: RoundState, prev: RoundState): void {

  const v = getView(next);

  for (const [name, value] of Object.entries(a)) {

  let cash = START_CASH;
  let shares = 0;
  let realized = 0;
  for (const t of trades) {
    if (t.side === 'BUY') {
      cash -= t.amount;
      shares += t.quantity;
    } else {
      cash += t.amount;
      shares -= t.quantity;
      realized += t.tradePnl ?? Number.NaN;
    }
  }
  check(cash === a.cash, `INV-04: cash ${a.cash} â‰  rebuilt ${cash}`);
  check(shares === a.shares, `INV-05: shares ${a.shares} â‰  rebuilt ${shares}`);
  check(realized === a.realizedPnl, `INV-06: realized ${a.realizedPnl} â‰  Î£ tradePnl ${realized}`);
  // INV-07 and HIST-06
  for (const t of trades) {
    if (t.type === 'player') {
      check(t.candleIndex >= 11 && t.candleIndex <= 70, `player trade at candle ${t.candleIndex}`);
      check(t.price === candleAt(next, t.candleIndex).open, `trade ${t.id} price ${t.price} â‰  open`);
    } else {

"""
TradeQuest â€” independent reference implementation of the price engine.

Purpose: produce the golden values used by the TypeScript tests (RNG-05, ENG-04)
WITHOUT running the TypeScript code under test (docs/rules.md Â§5.6).

It is written directly from docs/rules.md Â§5 in a different language. If the
TypeScript engine and this script disagree, one of them has a bug: investigate,
don't just regenerate the fixture. Regenerate only with an ENGINE_VERSION bump.

Usage (Python 3.8+, no packages needed):
    python tools/reference_engine.py > tests/fixtures/reference-v1.json
"""

import json
import math

ENGINE_VERSION = 1

TOTAL_CANDLES = 70
START_PRICE_MIN = 2000
START_PRICE_MAX = 5000
MIN_PRICE = 100
DRIFT = 0
BODY_SIGMA = 0.015
GAP_SIGMA = 0.002
MAX_MOVE = 0.10
MAX_GAP = 0.02
WICK_MAX = 0.01

MASK32 = 0xFFFFFFFF


def imul(a, b):
    """Low 32 bits of a * b (what JavaScript's Math.imul returns, as an unsigned bit pattern)."""
    return (a * b) & MASK32


class Mulberry32:
    """mulberry32, keeping every value as an unsigned 32-bit integer."""

    def __init__(self, seed):
        assert 0 <= seed <= MASK32
        self.state = seed
        self.draws = 0

    def next(self):
        self.draws += 1
        self.state = (self.state + 0x6D2B79F5) & MASK32
        s = self.state
        t = imul(s ^ (s >> 15), 1 | s)
        t = ((t + imul(t ^ (t >> 7), 61 | t)) & MASK32) ^ t
        return ((t ^ (t >> 14)) & MASK32) / 4294967296


def normal_z(rng):
    total = 0.0
    for _ in range(12):
        total += rng.next()
    return total - 6


def round_half_up(x):
    return math.floor(x + 0.5)


def clamp(x, lo, hi):
    return min(max(x, lo), hi)


def generate(rng, count=TOTAL_CANDLES):
    start = START_PRICE_MIN + math.floor(rng.next() * (START_PRICE_MAX - START_PRICE_MIN + 1))
    candles = []
    prev_close = None
    for i in range(1, count + 1):
        z_gap = normal_z(rng)
        z_body = normal_z(rng)
        u_up = rng.next()
        u_down = rng.next()
        if i == 1:
            o = start
        else:
            gap = clamp(GAP_SIGMA * z_gap, -MAX_GAP, MAX_GAP)
            o = max(MIN_PRICE, round_half_up(prev_close * (1 + gap)))
        ret = clamp(DRIFT + BODY_SIGMA * z_body, -MAX_MOVE, MAX_MOVE)
        c = max(MIN_PRICE, round_half_up(o * (1 + ret)))
        h = round_half_up(max(o, c) * (1 + u_up * WICK_MAX))
        lo = max(MIN_PRICE, round_half_up(min(o, c) * (1 - u_down * WICK_MAX)))
        candles.append({"index": i, "open": o, "high": h, "low": lo, "close": c})
        prev_close = c
    return candles


def main():
    rng_seeds = [12345, 0, 4294967295]
    candle_seeds = [12345, 1, 4294967295]

    rng_outputs = {}
    for seed in rng_seeds:
        r = Mulberry32(seed)
        rng_outputs[str(seed)] = [r.next() for _ in range(5)]

    candles = {}
    draw_counts = {}
    for seed in candle_seeds:
        r = Mulberry32(seed)
        candles[str(seed)] = generate(r)
        draw_counts[str(seed)] = r.draws

    print(json.dumps({
        "engineVersion": ENGINE_VERSION,
        "generatedBy": "tools/reference_engine.py (independent Python reference)",
        "rngFirstFive": rng_outputs,
        "drawCounts": draw_counts,
        "candles": candles,
    }, indent=1))


if __name__ == "__main__":
    main()

# TradeQuest â€” Milestone 1

A trading-education simulator. Milestone 1 is a single-player round on one **fictional** stock (Quellaris Energy, QLRX) with $1,000 of virtual cash: 10 history candles for context, then 60 playable candles, revealed one at a time. Everything is simulated â€” no real companies, prices or money.

The rules live in [`docs/rules.md`](docs/rules.md) and the test plan in [`docs/test-cases.md`](docs/test-cases.md). If the code and the rules disagree, the rules win.

## Requirements

- **Node.js 20.19+ or 22.12+** (check with `node -v`). Download the LTS version from nodejs.org if needed.
- Windows, macOS or Linux. Commands below work in PowerShell, Command Prompt or a terminal.
- Optional: Python 3, only if you want to re-run the independent reference engine.

## Run it

```bash
npm install        # first time only â€” downloads Vite, React, Vitest, TypeScript
npm run dev        # starts the site; open the address it prints (usually http://localhost:5173)
```

Other commands:

| Command | What it does |
|---------|--------------|
| `npm test` | Runs all automated tests once (Vitest) |
| `npm run test:watch` | Re-runs tests when you save a file |
| `npm run typecheck` | Checks TypeScript types |
| `npm run build` | Type-checks, then builds the site into `dist/` |
| `npm run preview` | Serves the built `dist/` folder |

## How to play

1. Read the 10 grey history candles. They cannot be traded at.
2. Choose Buy or Sell, type a whole number of shares (or press **Max**) and press **Place order**. The estimate uses the last close; the order actually fills at the **next candle's open**.
3. Press **Next candle â†’**. Your order fills (or is rejected if you can no longer afford it) and the next candle appears.
4. After candle 60, press **Finish round**. Any shares you still hold are sold at the final close.
5. On the results screen, **Replay this round** gives you exactly the same candles (same seed); **New round** gives a new market.

## Project structure

```

  constants.ts   all parameters (start cash, candle counts, volatilityâ€¦)
```

The engine never imports React, and React never sees the full list of 70 candles â€” only `getView(state)`, which contains candles 1..k.
